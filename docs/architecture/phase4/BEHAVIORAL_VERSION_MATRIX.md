## Meaning of an identifier

**P:** IDs below form the proposed catalog. Historical v1 IDs describe **inspected source policies**, not an authenticated assignment to an existing run. New v2 IDs describe future contracts and are unimplemented. A complete selection is behavior ID + immutable variant parameters/digest + implementation/source digest + reference-suite version + environment. No ID is an arbitrary Python import path. Unknown IDs or incomplete variants fail planning.

A run selects exactly one future contract for each C01-C14 family. Where a contract supports more than one historical algorithm or treatment, the variant parameter is mandatory and frozen; it is part of the resolved identity. No unrecorded scientific defaults are permitted. A change to accepted values, error behavior, gradient flow, draw order, arithmetic/cast, endpoint timing or inference unit receives a new ID/version or a new explicit variant, with protocol review even if the package API stays stable.

## Compatibility claims and promotion rules

1. **source_described_only:** source/byte/AST inspection supports the description; no execution or equality claim.
2. **contract_change:** an intentional change in domain, error, structure or metadata. It is not drop-in compatible even when typical valid-input arithmetic looks the same.
3. **fixture_agreement:** a future test report may establish equality or a justified tolerance on named fixtures in a named environment only. This is not full pipeline equivalence.
4. **replay_agreement:** a separately authorized replay may establish stated endpoint/statistical/numerical/bitwise agreement for one complete profile and dependency closure. State exactly which level and scope passed.
5. **independent_scientific_replication:** requires attributable independent work, protocol/data/source/environment records and saved results supporting the scientific comparison. New local seeds or an independent verifier function are insufficient by themselves.

Every row currently remains at source description or proposed contract change. There are **no verified-equivalent replacements** in this phase. A failed fixture is preserved and investigated; do not relax tolerances after seeing outcomes to manufacture compatibility.

## Reference-test acceptance policy

- Exact comparisons apply to declared discrete identities: bytes, hashes, permutations, sample indices, IDs, schema keys, transition order and where required initial-state tensors in a pinned environment.
- Floating-point comparisons must state absolute/relative tolerance, reduction dtype, device, backend, scale and rationale before execution. No universal epsilon or cross-GPU bitwise guarantee is frozen by this document. Phase 3B precision and Experiment 04 diagnostic tolerances remain historical study-specific facts.
- Include adversarial invalid inputs, not only successful paths: zero/negative/NaN/Inf bandwidth, shape/head mismatch, invalid permutations, short schedules, missing pairs, unsupported checkpoints and denied test access.
- Tests that invoke model forward/autograd, optimizer steps, checkpoint loading or evaluation are future execution and require explicit authorization, new destinations and agreed budgets. Phase 4 only checks documentation structure and source references.
- A reference source pin is a full file/source-closure digest with location and symbol, not the current branch name. Full historical replay is blocked where executing-source identity is unresolved; a source-derived fixture can still be clearly labeled as such.

## Historical differences that must remain visible

**V/S:** [GatedLinear.forward](../../../conn_experiment_01/src/conn_exp/models.py#L23) detaches and casts G, whereas [effective_weight](../../../CoNN_Associative_Relationships/src/conn_assoc/gate.py#L44) is a differentiable product. [batch_indices](../../../conn_experiment_01/src/conn_exp/train.py#L39) cycles one fixed permutation, whereas [paired_batches](../../../conn_experiment_01/src/conn_exp/har_core.py#L57) draws repeated epoch permutations. [Factor.forward](../../../CoNN_Associative_Relationships/phase3b_context_diagnostics/src/models.py#L19) casts contextual modulation to float32 after variant-dependent storage arithmetic. [Gates.build](../../../CoNN_Associative_Relationships/src/conn_assoc/phase23_core.py#L105) embeds 3200/2240 timing; [release_step_index](../../../conn_experiment_01/src/conn_exp/schedules.py#L24) computes a configurable rounded boundary. [paired](../../../experiments/experiment_04/src/conn_exp04/analysis.py#L13) rejects nonfinite seed differences and uses exact sign flips, while historical [paired_summary](../../../conn_experiment_01/src/conn_exp/evaluation.py#L68) filters nonfinite values. These are verified source differences, not new measured results.

**U:** Exact early executing source, source stage per Phase 2/3 fit/resume, complete environment closure and cross-platform numerical agreement remain unknown. Descriptor names must not be written back into historical manifests as if known at execution time.
